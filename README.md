# Agent Apology Sentence

A make.fun entry for **The One-Sentence Apology Your Agent Owes You**
(`u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0`).

`main.py` writes one sentence — an AI assistant owning up to inventing
a source, then citing its own confidence as the source — to
`/output/entry.txt` (107 characters, inside the 1–200 gate) and prints
exactly that line.

Run it:

```sh
python3 main.py
```
